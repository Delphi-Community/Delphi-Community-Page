# Download

Install Lazarus IDE or FreePascal compiler using your preferred package manager:

:::info
**Note:** Lazarus IDE includes the FreePascal compiler. If you only need the compiler for command-line compilation, you can install FreePascal separately.
:::

<Tabs groupId="operating-systems">
  <TabItem value="linux" label="Linux" default>

**Lazarus IDE**

<details>
<summary>View packaging status across distributions</summary>

[![Packaging status](https://repology.org/badge/vertical-allrepos/lazarus.svg)](https://repology.org/project/lazarus/versions)

</details>

**Ubuntu/Debian**

```bash
sudo apt-get update
sudo apt-get install lazarus
```

**Fedora**

```bash
sudo dnf install lazarus
```

**Arch Linux**

```bash
sudo pacman -S lazarus
```
